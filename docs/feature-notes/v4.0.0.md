## Visual rationale

- Color: neutral canvases keep project evidence prominent; a restrained green-gray accent identifies profile and interaction focus.
- Typography: system sans-serif avoids font downloads and gives the career record a clear, familiar hierarchy.
- Layout: one reading column removes competing sidebars; the profile leads so visitors immediately understand the engineer behind the work.
- Spacing: section rules and a regular spacing scale separate career information without decorative panels.
- Images: retain the actual portrait and project work; small thumbnails support scanning rather than filling the screen.
- Motion: hover feedback only, respecting reduced motion. Energy 1 / Rhythm 1 / Motion 1.
